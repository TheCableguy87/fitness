# כושר ביתי (PWA)

אפליקציית אימונים ביתית בעברית, RTL, כהה בלבד. HTML/CSS/JS רגיל עם ES modules: בלי build, בלי npm ובלי ספריות. הנתונים נשמרים ב-localStorage בלבד.

## הרצה מקומית

דרוש Node 18 ומעלה (לשרת הסטטי ולבדיקות בלבד).

```bash
node tools/serve.js 5173
```

פתח `http://localhost:5173`. לייבוא בדיקה: מסך ייבוא, הדבק את `data/sample-plan.json` או בחר אותו כקובץ.

הערת פיתוח: ה-Service Worker עובד cache-first, ולכן בזמן פיתוח צריך לבטל רישום ולנקות מטמון (DevTools, Application) או להעלות את `VERSION` ב-`sw.js` ולאשר "עדכן" בבית. בכל שחרור יש להעלות את `VERSION`.

## בדיקות

```bash
node --test "tests/*.test.js"
```

מכסות ולידציה, טיימר לפי חותמת זמן, אחסון ומיגרציה, מיזוג גיבוי ותזכורת, לוגיקת אימון וטיוטה, וספריית התרגילים. דוגמאות נתונים ב-`tests/fixtures/`.

## מבנה

- `index.html`, `manifest.json`, `sw.js`, `icons/` (אייקון 180x180 נוצר ב-`tools/make-icons.js`)
- `js/`: `app.js` (ראוטר), `store.js` (מצב ואחסון), `storage.js`, `validate.js`, `timer.js`, `workoutState.js`, `draft.js`, `backup.js`, `library.js`, `audio.js`, `wakelock.js`, `errors.js`, `ui.js`
- `js/views/`: `home`, `day`, `import`, `workout`, `summary`, `explain`, `settings`
- `data/exercises.json` (ספריית ההסברים, לקריאה בלבד), `data/sample-plan.json`

כל הנתיבים יחסיים, כך שהאתר יכול לרוץ תחת תת-נתיב (GitHub Pages).

## צ'קליסט ידני באייפון (סעיף 6 בתוכנית)

אחרי פריסה, ב-Safari: הוספה למסך הבית ופתיחה מהאייקון. לייבא ולהזין נתונים רק אחרי ההתקנה (האחסון נפרד בין Safari לאפליקציה המותקנת).

- [ ] גרסת iOS ותמיכת Wake Lock: האם המסך נשאר דלוק באימון, ואם לא, האם מופיעה ההודעה על נעילה אוטומטית
- [ ] התקנה במסך הבית, פתיחה במסך מלא (standalone), בלי סרגל Safari, בלי חפיפה עם ה-Dynamic Island
- [ ] אופליין: מצב טיסה, סגירה ופתיחה מחדש, האפליקציה וההסברים נטענים
- [ ] ייבוא תוכנית מהדבקה ומקובץ, כולל קובץ שגוי (הודעת שגיאה עם נתיב)
- [ ] אימון מלא: סט חזרות עם שינוי ערך, טיימר פלאנק, צד ימין ושמאל, מנוחה, צליל סיום (ובמצב שקט: רק חזותי)
- [ ] נעילת מסך באמצע טיימר ופתיחה מחדש: הזמן נכון לפי השעון
- [ ] מעבר לאפליקציה אחרת באמצע טיימר וחזרה
- [ ] סגירה מלאה באמצע אימון, פתיחה: כרטיס "המשך", והמשך מאותה נקודה
- [ ] "איך עושים" מהאימון ומפרטי היום, כולל גרסה קלה/קשה, ופתיחה באמצע טיימר
- [ ] סיכום עם RPE וכאב ושמירה, חזרה לבית והפס השבועי
- [ ] ייצוא גיבוי (גיליון שיתוף, שמירה לקבצים) וייבוא שלו, מיזוג והחלפה
- [ ] תזכורת גיבוי (אחרי 7 ימים או 5 אימונים)
- [ ] עדכון גרסה: העלאת `VERSION`, פתיחה, באנר "יש גרסה חדשה" בבית בלבד, "עדכן"
